# Binary Tree

Binary tree and binary search tree programs in C.

- `insert.c` – insertion in a binary search tree
- `search.c` – searching a node
- `delete-node.c` – deleting a node
- `delete-tree.c` – deleting the whole tree
- `leafnode.c` – leaf node handling
- `traverse-array.c` – traversal using array implementation
- `traverse-linklist.c` – traversal using linked list implementation
- `Inorder-iterative.c` – iterative inorder traversal
- `preorder-iterative.c` – iterative preorder traversal
- `postorder-iterative.c` – iterative postorder traversal
